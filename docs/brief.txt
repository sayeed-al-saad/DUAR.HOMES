Build a production-quality MVP for a Bangladesh real-estate search engine and marketplace.

PROJECT CONCEPT

The website is a Bangladesh-focused property search engine that combines:
1. Our own property listings
2. Publicly discoverable property information from external sources where legally and technically permitted
3. Partner/authorized feeds
4. Manual/admin imports

The product should eventually become “Google for real estate in Bangladesh.”

IMPORTANT CONTENT/PERSONAL-DATA RULES

Do NOT design the system around blindly copying entire third-party listings.

For external listings, the default stored/displayed information should be limited to useful property facts such as:
- property type
- sale/rent
- price
- area
- size
- bedrooms
- bathrooms
- location
- amenities
- listing date when available
- source name
- original listing URL
- last checked timestamp

Do not automatically copy third-party:
- phone numbers
- private contact details
- full descriptions
- copyrighted photos
- logos/trademarks
- account-only content
- login-protected content

unless the source/rights holder has explicitly authorized it.

Do not bypass CAPTCHA, authentication, access controls, rate limits, or other technical restrictions.

Implement source-specific ingestion adapters so each source can be enabled/disabled independently.

Add source attribution on every external listing and a clear “View Original Listing” link.

Use conservative defaults for privacy and copyright risk.

- price
- size
- bedrooms
- bathrooms

- normalized address
- source URL

- phone number only for authorized first-party data, not scraped third-party contact data
